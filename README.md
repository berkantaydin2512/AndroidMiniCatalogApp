# Mini Katalog Android Uygulaması

Ürünleri listeleme, sepete ekleme ve ödeme ekranı içeren Flutter uygulaması.

- **Flutter sürümü:** 3.47.8

## Çalıştırma

1. Flutter SDK 3.47.8'i ve Android geliştirme araçlarını yükleyin.
2. Proje klasöründe terminal açıp ortamı kontrol edin:

   ```bash
   flutter doctor
   ```

3. Proje bağımlılıklarını yükleyin:

   ```bash
   flutter pub get
   ```

4. Android emülatörünü başlatın.

   ```bash
   Önceden yüklemiş olduğunuz Android Studio telefon emülatörlerinden.
   ```

5. Uygulamayı çalıştırın :

   ```bash
   flutter run
   ```
